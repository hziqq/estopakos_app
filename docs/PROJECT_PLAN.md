| Sprint | Tujuan sprint | Increment (keluaran) |

| 1 | Identifikasi masalah dan analisis kebutuhan | Proposal, deskripsi permasalahan, daftar kebutuhan |
| 2 | Analisis dan perancangan | SRS final, Use Case, Activity, Sequence, Class Diagram, ERD, desain UI/UX dan prototipe |

| 5 | Keluhan, pengumuman, penyempurnaan | Aplikasi lengkap, hasil uji, laporan akhir |
